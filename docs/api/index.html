rol/Personaje.kt

clase abstracta

Personaje

abstract class Personaje(val nombre: String, val vidaMaxima: Int, val arma: Arma)

Personaje del juego: la clase base de héroes y enemigos.

Es abstracta porque cada tipo de personaje debe indicar su ataqueBase. Cada personaje recibe un id único al crearse, gracias al contador del companion object.

Propiedad nombre
nombre del personaje.
Propiedad vidaMaxima
vida con la que empieza y que nunca puede superar.
Propiedad arma
arma que lleva; su daño se suma al ataqueBase.
Subclases conocidas
Guerrero, Mago, Arquero, Enemigo
Miembros
objectcompanion object
companion object

Lo que pertenece a la clase y no a cada personaje: el contador de identificadores. Es privado, así que solo Personaje puede cambiarlo.

propiedadid
val id: Int

Identificador único (1, 2, 3…), asignado en el bloque init al crear el personaje.

propiedadvida
var vida: Int = vidaMaxima

Vida actual del personaje.

El setter la mantiene siempre entre 0 y vidaMaxima: si se intenta guardar un valor negativo se queda en 0, y si se pasa del máximo se queda en el máximo.

propiedadestaVivo
val estaVivo: Boolean

true mientras la vida sea mayor que 0. Se calcula cada vez que se lee.

propiedadataqueBaseabstract
abstract val ataqueBase: Int

Daño que hace el personaje sin contar el arma. Lo fija cada subclase.

funcióncalcularDanoopen
open fun calcularDano(objetivo: Personaje): Int

Calcula el daño que este personaje hace a objetivo: ataqueBase más el daño del arma. Las subclases pueden cambiarlo (por ejemplo, Guerrero).

Parámetro objetivo
personaje que va a recibir el ataque.
Devuelve
el daño que se le va a hacer.
funciónatacaropen
open fun atacar(objetivo: Personaje)

Ataca a objetivo: muestra el ataque y le hace el daño de calcularDano. Mago y Arquero lo sobrescriben.

Parámetro objetivo
personaje atacado.
funciónrecibirDanoopen
open fun recibirDano(cantidad: Int)

Resta cantidad a la vida, muestra cuánta le queda y avisa si el personaje cae. Guerrero lo sobrescribe para aplicar su armadura.

Parámetro cantidad
daño recibido.

Arma

enum class Arma(val texto: String, val dano: Int)

Armas del juego. Cada personaje lleva una, que suma su daño al ataque base.

Propiedad texto
nombre del arma tal y como se muestra en los mensajes.
Propiedad dano

Sanador

interface Sanador

Habilidad de curar. La tienen Mago y Trol, aunque uno es héroe y el otro enemigo: por eso es una interfaz y no una clase.

Subclases conocidas

Miembros

propiedadpoderCuracion

funcióncurar
fun curar(objetivo: Personaje)

Cura a objetivo sumándole poderCuracion puntos de vida (sin pasar de su vida máxima). Un personaje que ha caído ya no se puede curar.

Parámetro objetivo

Pocion

data class Pocion(val nombre: String, val curacion: Int)

Poción del inventario (reto). Al ser data class, dos pociones con el mismo nombre y curación son iguales, así que sirve como clave del Partida.inventario.

Propiedad nombre

Propiedad curacion

Partida

object Partida

La partida en curso. Es un object: solo hay una partida en todo el programa y se usa por su nombre, sin crearla.

Guarda los dos equipos, la ronda actual y el inventario de pociones, y contiene toda la lógica del combate.

funciónjugarRonda
fun jugarRonda()

Juega una ronda completa en tres pasos:

  • Cada héroe vivo ataca al primer enemigo vivo.
  • Cada enemigo vivo ataca al héroe vivo con más vida.
  • Los sanadores de cada equipo curan al compañero herido con menos vida.

Prueba de las partes 1 a 4 del enunciado: crea un personaje de cada tipo y comprueba ataques, el setter de la vida, la curación y el vuelo.
